Maestro Site Failover Calc Tool

Local standalone calculator with a built-in scenario library. No VBA, no Excel macros, no installation. Author - Yury Butuzov

This tool runs entirely in the browser. Scenarios are stored in your browser's local storage on this computer. You can export them to JSON or CSV at any time.

How to use

  1. Set the component weights and the minimum failover gap.
  2. Enter a scenario name and the current active Site.
  3. Fill the component totals and UP values for both Site.
  4. Use Add as New to create a saved scenario.
  5. Later, choose a saved scenario and click Load Selected.
  6. After changes, use Apply to Selected to update the saved scenario.
  7. Use Export JSON for backup and Export CSV to open the scenario list in Excel.

This file contains no VBA and is not an Excel macro file. Whether your environment allows opening local HTML files is controlled by your browser and company policy.
